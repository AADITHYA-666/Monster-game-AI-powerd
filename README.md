# Monster Hunter Platformer

A platformer game with monster hunting, weapon crafting, and mech building mechanics. Built with Pygame CE.

## Features

- Platformer gameplay with smooth movement and jumping
- Multiple weapons with different characteristics
- Mech system with different types and weapon slots
- Monster AI with health and damage systems
- Resource collection system
- Particle effects and visual feedback
- Health bars and UI elements

## Game Mechanics

### Movement
- Use LEFT/RIGHT arrow keys to move
- SPACE to jump
- Platforms provide different paths and challenges

### Combat
- Left-click to shoot
- Keys 1-3 to switch between weapons:
  - Basic Gun: Balanced damage and fire rate
  - Shotgun: High damage, short range
  - Sniper: Very high damage, long range, slow fire rate

### Mechs
- Press M to toggle mech mode
- Two mech types available:
  - Light Mech: Faster, 2 weapon slots
  - Heavy Mech: More health, 3 weapon slots

### Resources
- Collect resources from defeated monsters:
  - Metal: Used for weapon upgrades
  - Energy: Powers mechs
  - Parts: Used for crafting

## Requirements

- Python 3.8 or higher
- Pygame CE
- NumPy

## Installation

1. Clone this repository
2. Install the required packages:
```bash
pip install -r requirements.txt
```

## How to Play

1. Run the game:
```bash
python main.py
```

2. Controls:
- Arrow Keys: Move
- SPACE: Jump
- Left Click: Shoot
- 1-3: Switch Weapons
- M: Toggle Mech
- ESC: Quit

## Game Objectives

1. Hunt monsters to collect resources
2. Build and upgrade weapons
3. Craft and customize mechs
4. Survive and progress through increasingly difficult levels

Enjoy the game!
